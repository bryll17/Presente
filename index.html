Bulk add (paste list)

Export attendance

CSV = one row per mark with the exact scan time (best for Excel / SF2 encoding). PDF & Word = register grid, students × dates, letters only. Time log = chronological list of who was marked when, to the second. “Word” downloads as a .doc that Word opens with a compatibility notice — normal.

Prints a cut-out grid. Laminate or have students keep them in their IDs.

Recovery tool: after restoring a backup or connecting a brand-new Sheet, this re-uploads every mark and the whole roster from this device. Safe to press — duplicates are ignored.

Auto-backup to this computer

Works in Chrome or Edge on a computer. Pick a folder once; every time the app is open here, it silently saves a dated backup file plus a plain CSV of all marks into that folder — your own copy even if Google and GitHub both vanished. Runs only while the app is open on this computer.

One-time sync setup (≈10 min)
  1. On a computer (easiest), go to sheet.new to make a blank Google Sheet. Name it e.g. Presente Data. Keep it private.
  2. In the Sheet: Extensions → Apps Script. Delete the sample code, paste the script below.
  3. In the script, change TOKEN to your own secret word. Save.
  4. Deploy → New deployment → Web app. Execute as: Me. Who has access: Anyone. Deploy, approve the permissions, copy the Web app URL.
  5. Paste that URL and your token above — on both your phone and iPad — then tap Sync now.

Treat the URL + token like a key. Anyone who has both can read and write your attendance data. Don’t share them.

Updating the script later (new version of Presente): open the Sheet → Extensions → Apps Script → replace the code → save → Deploy → Manage deployments → pencil ✎ → Version: New version → Deploy. The URL stays the same, so your devices keep working.

Email confirmations: to email students/parents when they’re scanned, set SEND_EMAILS = true at the top of the script and add email addresses to students in the Roster tab (✎ edit). Sending happens when marks reach the Sheet, and Google caps it at ~100 recipients/day on a normal Gmail account (1,500/day on a Workspace/DepEd account).


    

  


  

    How to use / notes
    

      
    
        
  • Door routine: open Presente while you still have internet, pick the class, Start camera, students file past. The big stamp shows the name — glance at the face. Already-marked students get an amber “ALREADY” stamp.
    • 
        
  • Late: when the bell rings, flip the toggle to Late and keep scanning.
    • 
        
  • Close the day: Records tab → “Mark unmarked as Absent”. Fix mistakes by tapping the chip.
    • 
        
  • Exact times: every scan is stamped to the second, using this device’s clock — keep it on automatic time. See it under each name in Records, or export a Time log.
    • 
        
  • Forgot / lost card: use “Tap a name” on the Scan tab, or reprint from Export.
    • 
        
  • Offline: everything saves locally first. Marks upload automatically when you’re back online (watch the dot in the header). If both devices edit the same student’s same day, the latest change wins.
    • 
        
  • Don’t clear this browser’s data — that deletes local records. Backups exist for a reason.
    • 
        
  • Photo mode exists for devices where live camera fails: it opens the camera app, you snap the QR, it decodes the photo.
    • 
        
  • Online classes: Scan tab → “Online class check-in link…” → pick class and time limit → send the link. Students scan their own QR card on that page and get marked Present with the exact time; the link dies at the deadline. They can’t see anyone’s records — only submit their own code. Marks flow into your Sheet and devices like normal scans (“self check-in”).
